Bạn là Senior Frontend Architect. Hãy xây dựng hoàn chỉnh ứng dụng web "BunTech" — Hệ thống chuyển đổi số toàn diện cho Xưởng Bún gia đình.

## CÔNG NGHỆ BẮT BUỘC
- **Framework:** Nuxt 4 + Vue 3 (Composition API) + TypeScript
- **Styling:** TailwindCSS (Design Token: primary, secondary, accent, danger, warning, success)
- **State:** Pinia
- **Form:** VeeValidate + Yup Schema Validation
- **HTTP:** Axios (withCredentials: true) + Interceptors tập trung
- **Icons:** lucide-vue-next (tree-shakable)
- **i18n:** vue-i18n — mọi string phải qua `$t('key')`, KHÔNG hardcode text
- **Table lớn:** vue-virtual-scroller (Virtualization)
- **Offline:** idb-keyval (Offline Sync Queue cho Driver App)
- **Chart:** ECharts hoặc Chart.js (Lazy import)
- **Rich Text:** TipTap Editor (cho Blog CMS)
- **Font:** Google Fonts (Inter hoặc Be Vietnam Pro)

## ACTORS (4 loại người dùng)
1. **Admin (Chủ xưởng):** Toàn quyền quản lý hệ thống.
2. **Driver (Tài xế):** App mobile xem tuyến đường, chốt giao hàng.
3. **Customer (Khách sỉ):** Đăng nhập, đặt hàng, xem công nợ, có bảng giá riêng.
4. **Guest (Khách vãng lai):** Xem trang chủ, tin tức, đặt đơn nhanh.

## TOÀN BỘ MÀN HÌNH CẦN SINH

### A. WEB ADMIN (Layout: Sidebar trái co/giãn + Topbar avatar/dropdown/noti)

#### A1. Authentication & Profile
- **Đăng nhập Admin:** Layout split-screen (1 bên banner, 1 bên form). Gọi `/auth/login` kèm Header `X-Client-Type: WEB`. Lưu token bằng HttpOnly Cookie (BE set). Nút Enter submit.
- **Quên mật khẩu:** Form nhập email/SĐT → gọi API reset → hiện thông báo "Đã gửi link đặt lại mật khẩu".
- **Đặt lại mật khẩu:** Form nhập mật khẩu mới (≥6 ký tự) + xác nhận.
- **Xem hồ sơ cá nhân:** Hiển thị thông tin Admin đang đăng nhập.
- **Đổi mật khẩu cá nhân:** Form mật khẩu cũ + mật khẩu mới + xác nhận.

#### A2. Dashboard
- **Tổng quan:** Các Card KPI (Doanh thu hôm nay, Số đơn, Khách mới, Tồn kho).
- **Biểu đồ doanh thu:** Time-series chart (Line/Bar) với DateRange filter (`startDate` ≤ `endDate` ≤ now). Lazy import component chart.
- **Top Buyers:** Bảng xếp hạng khách mua nhiều nhất (có avatar, tên, tổng tiền).
- Khi load: hiển thị Skeleton Loader, KHÔNG spinner.

#### A3. Quản lý Khách hàng (Users)
- **Danh sách khách hàng:** DataTable có Virtual Scroller. Cột: ID (căn giữa), Tên, SĐT (10-11 số), Email, Role Badge, Trạng thái, Hành động (cột fixed phải). Search Debounce 300ms, push `?search=` lên URL. Filter: Role (Select), Status. Sort click header. Pagination server-side (Prev/Next/Page/RowsPerPage: 10/20/50). Click đúp dòng → xem chi tiết. Compact density. Hover highlight row.
- **Chi tiết khách hàng:** Tabs gồm:
  - Tab Lịch sử Đơn hàng
  - Tab Công nợ (hiển thị tổng nợ, hạn mức `debtLimit`)
  - Tab Sổ địa chỉ (CRUD, một địa chỉ `isDefault: true` → tự tháo isDefault các địa chỉ khác)
  - Tab Bảng giá riêng (Custom Price — 1 mức giá cố định/khách, KHÔNG tier-pricing)
- **Thêm/Sửa khách hàng:** Drawer trượt từ phải. Validate SĐT 10-11 số, mật khẩu ≥6 ký tự. Required fields có dấu `*` đỏ.

#### A4. Quản lý Sản phẩm (Products)
- **Quản lý Danh mục:** CRUD danh mục sản phẩm.
- **Danh sách sản phẩm:** DataTable + Filter trạng thái + Search + Sort + Pagination. Thumbnail ảnh SP.
- **Thêm/Sửa sản phẩm:** Form có Drag & Drop Dropzone upload ảnh. Preview thumbnail bằng `URL.createObjectURL` trước submit. Xóa ảnh preview. Giới hạn 2MB/5MB, báo lỗi vượt dung lượng. Soft-delete.
- **Quản lý Đánh giá (Reviews):** Danh sách review, duyệt/từ chối (`isApproved` true/false), trả lời review. Áp dụng Optimistic UI Update khi bấm duyệt (update UI ngay → gọi API ngầm → rollback nếu lỗi).

#### A5. Quản lý Đơn hàng (Orders)
- **Danh sách đơn hàng:** DataTable. Filter theo OrderStatus (PENDING, PROCESSING, SHIPPING, DELIVERED, CANCELLED). DateRange picker. Search. Sort. Pagination. Realtime update qua SSE (`EventSource` tới `GET /api/v1/admin/events/sse`) — khi tài xế chốt đơn, dòng tự nhảy trạng thái không cần F5.
- **Chi tiết đơn hàng:** Hiển thị thông tin khách, danh sách SP, tổng tiền. Nút "Copy đơn" → điều hướng sang `/admin/orders/create` + fill sẵn data khách và list SP từ đơn cũ (FE tự xử lý parse → fill → cho sửa → submit tạo mới). Áp dụng Optimistic Locking: gửi `updatedAt` khi đổi trạng thái, bắt lỗi 409 → Dialog "Dữ liệu đã bị thay đổi bởi người khác, vui lòng tải lại".
- **Form tạo đơn Admin:** Chọn User → tự động gọi API fetch Custom Price của user đó → đè giá riêng lên danh sách Products hiển thị. Tự tính tổng tiền. Cảnh báo nếu tồn kho = 0 (out of stock). Cảnh báo nếu khách vượt hạn mức nợ (`debtLimit`): Toast đỏ "Khách hàng [Tên] đã vượt hạn mức nợ...". Format tiền VND real-time khi gõ. Validate `amountCollected`: truyền 0 nếu ghi nợ 100%, bằng tổng bill nếu trả đủ.
- **Xuất CSV đơn hàng ngày:** Gọi `GET /exports/orders-today` → nhận Blob → tạo hidden link tải file `Orders_Today.csv`. Spinner trên nút Export khi chờ.
- **Màn hình điều phối Batch Assign:** Gom nhiều đơn PROCESSING → chọn Tài xế → gọi `PATCH /admin/orders/batch-assign`. Push Notification cho Tài xế.

#### A6. Tài chính (Finance)
- **Sổ cái giao dịch (Transactions):** DataTable filter theo TransactionType (PAYMENT, REFUND, DEBT_INCREASE, DEBT_PAYMENT). Cột tiền căn phải. DateRange. Pagination.
- **Thanh toán nợ (Pay Debt):** Form chọn khách → nhập số tiền → submit. Confirm Dialog trước khi thực hiện.

#### A7. Kho vận (Inventory)
- **Tồn kho:** Danh sách nguyên vật liệu + số lượng hiện tại.
- **Nhập kho (Import):** Form nhập gạo/nguyên liệu. Validate số lượng > 0.
- **Xuất kho (Export):** Form xuất nguyên liệu. Bắt lỗi 400 nếu xuất > tồn kho → highlight ô Input viền đỏ. Soft-delete.
- **Báo cáo hao hụt (Loss Report):** Đối chiếu gạo xuất vs bún bán ra → hiển thị tỷ lệ hao hụt.

#### A8. CMS & Blog
- **Quản lý danh mục blog:** CRUD.
- **Viết/Sửa bài:** Rich Text Editor (TipTap). Upload ảnh trong bài. Preview bài viết. Soft-delete. Sanitize HTML bằng DOMPurify khi render `v-html`.

#### A9. Cấu hình hệ thống
- **System Config:** Các thiết lập hệ thống chung.

## QUY TẮC UX/UI BẮT BUỘC

### Loading States
- **Chuyển route:** NProgress bar ngang trên cùng.
- **Submit form:** Spinner trong nút bấm + disabled chống spam.
- **Fetch data:** Skeleton Loader (khối xám nhấp nháy), KHÔNG spinner xoay.

### Empty State
- Khi danh sách trống: Illustration + text "Chưa có dữ liệu" + nút CTA ("Tạo đơn ngay").

### Error Handling (Centralized Interceptor)
- HTTP 400/422: Parse mảng lỗi VineJS → map viền đỏ vào input tương ứng (VeeValidate).
- HTTP 401: Auto logout, xóa token, redirect Login.
- HTTP 403: Dialog "Bạn không có quyền tác vụ này".
- HTTP 409: Dialog "Dữ liệu đã bị thay đổi bởi người khác, vui lòng tải lại".
- HTTP 500: Toast đỏ "Hệ thống đang bận".

### Notification
- Toast Notification góc phải trên (Xanh = Success, Đỏ = Error) cho CRUD.
- Push Notification (FCM) cho Driver App → badge đỏ hoặc In-app Banner.

### Dialog xác nhận
- Cho tác vụ nguy hiểm (Xóa, Hủy đơn): Nút Cancel (xám, trái) + Nút Action (đỏ/xanh, phải). Click outside đóng, ESC đóng.

### Drawer
- Form ngắn (Thêm/Sửa user, sản phẩm): Drawer trượt từ phải.
- Filter nâng cao trên mobile: Drawer.

### Modal
- Thêm địa chỉ, Cài giá Custom Price, Xem ảnh phóng to.
- Click outside đóng, ESC đóng. Focus Trap (`useFocusTrap`).

### Breadcrumb
- Bắt buộc ở Admin: `Trang chủ > Quản lý Đơn hàng > Chi tiết đơn #123`. Dùng `<NuxtLink>`.

### Table
- Fixed header, Fixed cột Action (phải). Compact density. Giá tiền căn phải, ID căn giữa, text căn trái. Click đúp → chi tiết. Hover highlight row.

### Search
- Debounce 300-500ms. Sync `?search=` lên URL.

### Filter
- Phía trên Table. Sync 2 chiều với URL Query Params.

### Sort
- Click header cột. Icon Asc/Desc. Params `?sortBy=&sortDirection=`.

### Pagination
- Server-side 100%. Prev/Next/Page/RowsPerPage (10/20/50). `limit ≤ 100`.

### Responsive
- Customer Site & Driver App: Mobile-first.
- Admin: Desktop-first (Full HD). Table mobile → `overflow-x: auto`.

### Desktop
- Keyboard shortcuts: Enter submit Login/Search. Hover states.

### Mobile
- Touch target ≥ 44×44px. Pull-to-refresh Driver App. Native DatePicker.

## QUY TẮC KỸ THUẬT BẮT BUỘC

### Auth & Security
- Web: HttpOnly Cookie qua Header `X-Client-Type: WEB`. `withCredentials: true`.
- Driver: Secure Storage native (Capacitor Plugin).
- Refresh Token để duy trì đăng nhập dài ngày.
- Router Guards: Nuxt Middleware `auth.global.ts`. Check token → redirect Login nếu hết hạn. Check Role: `/admin` → `role === 'ADMIN'`. Silent Auth cho Customer Site.
- Custom Directive `v-permission="['ADMIN']"` ẩn nút khỏi DOM.
- Sanitize HTML blog bằng DOMPurify khi dùng `v-html`.

### API Layer
- Axios Interceptors tại `core/api/index.ts`.
- Master Data cache bằng ETag: kẹp `If-None-Match`, BE trả 304 → load cực nhanh.
- Pinia Store lưu cache Tỉnh/Thành bằng cờ `isLoaded`.
- SSE Realtime: `EventSource` tới `GET /api/v1/admin/events/sse` cho danh sách đơn Admin.

### Data Flow
- Repository → Service → Component. Component KHÔNG gọi API trực tiếp.
- Shared Components: chỉ `props` in + `emits` out. KHÔNG fetch API.
- Feature Components: Smart, inject Store/Service.
- DTO + Mapper: snake_case API → camelCase FE. `core/mappers/`.
- Enum: `OrderStatus`, `Role`, `TransactionType`.
- Constants: `DATE_FORMAT = 'DD/MM/YYYY'`, `MAX_FILE_SIZE`.

### State Management
- Pinia chỉ cho global state (Auth, MasterData).
- Local state dùng `ref()` trong component.
- Cache Invalidation: sau POST/PUT/DELETE → `clearNuxtData('key')` hoặc `refresh()`.

### Performance
- Lazy load ảnh: `<NuxtImg loading="lazy" />`.
- Lazy import component nặng: `<LazyDashboardChart />`, `defineAsyncComponent()`.
- Code Splitting tự động theo Route (Nuxt 4).
- Icon tree-shakable (lucide-vue-next).
- `computed()` thay `watch` khi có thể. `watch` chỉ khi trigger side-effects.
- `toRefs()` khi destructure props.
- Dọn dẹp event listener/interval trong `onUnmounted` (chống Memory Leak).

### Code Convention
- `<script setup lang="ts">` 100%.
- ESLint (chuẩn Nuxt) + Prettier + Husky pre-commit.
- Component ≤ 400 dòng.
- PascalCase component. camelCase variables. UPPER_SNAKE_CASE constants. Composable bắt đầu `use`.
- Logger: dùng Consola, KHÔNG `console.log()`.
- Env vars: `runtimeConfig` trong `nuxt.config.ts`, truy cập bằng `useRuntimeConfig()`. KHÔNG hardcode URL.

### Business Rules
- Khách sỉ: giá từ Bảng giá riêng (1 mức cố định/khách, KHÔNG tier-pricing).
- Đặt hàng nhanh: bắt buộc `website_url` rỗng (Honeypot).
- Zalo ZNS: BE tự động chạy ngầm, FE KHÔNG tích hợp.
- Địa chỉ `isDefault: true` → tự tháo isDefault các địa chỉ khác.
- Soft-delete: Kho, Sản phẩm, Bài viết.
- `amountCollected`: 0 = ghi nợ 100%, bằng tổng bill = trả đủ.
- SĐT: 10-11 số. Mật khẩu: ≥ 6 ký tự.

### Enums & Status
- OrderStatus: PENDING, PROCESSING, SHIPPING, DELIVERED, CANCELLED
- Role: ADMIN, DRIVER, CUSTOMER
- TransactionType: PAYMENT, REFUND, DEBT_INCREASE, DEBT_PAYMENT

### Edge Cases
- Tài khoản bị xóa/đổi mật khẩu khi đang login → API 401 → Interceptor văng ra Login.
- Xung đột ghi đè (Optimistic Locking) → 409 Conflict → Dialog reload.
- Cache Tỉnh/Thành 304: `If-None-Match`.
- Pagination limit ≤ 100, vượt → BE chặn 422.
- Khách vượt hạn mức nợ → API lỗi → cảnh báo đỏ.
- Xuất kho > tồn kho → 400 → highlight viền đỏ ô input.
