## 2. RÀ SOÁT UX PATTERNS

- [ ] Mọi DataTable: Fixed header + Fixed cột Action phải + Compact density + Giá căn phải + ID căn giữa + Text căn trái + Click đúp xem chi tiết + Hover row

- [ ] Toast: góc phải trên, Xanh Success / Đỏ Error

## 3. RÀ SOÁT ERROR HANDLING

- [ ] Interceptor 400/422: parse lỗi VineJS → viền đỏ input tương ứng

- [ ] Interceptor 403: Dialog "Không có quyền"

- [ ] Vượt debtLimit: cảnh báo đỏ kèm tên khách
- [ ] Xuất kho > tồn kho: viền đỏ ô input
